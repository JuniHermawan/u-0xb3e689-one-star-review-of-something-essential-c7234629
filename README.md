A deadpan one-star review of an everyday essential, in one line of 160 characters or fewer.

## The review

> One star. Gravity dropped my new phone face-down on concrete and has never once picked anything up.

Gravity is the essential: it drops the phone and never picks anything back up. The complaint is filed in earnest against a thing that cannot be fixed, and the sting lands in the last few words.

## Run it

```sh
python3 main.py
```

Writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13 standard library only. The program self-checks the gate before writing: 1–160 characters, one line, no exclamation marks, and re-reads the written file to confirm it is byte-identical to the reviewed text.
